# Phase 4 Findings

## Decisions
- Search-first + cluster expansion (NOT cluster-first as default)
- Cluster-first only as browse mode alternative

## Research
- Cluster hypothesis holds well for semantic embeddings
- Boundary documents between clusters get missed with cluster-first
- Sibling expansion adds semantically related context the user didn't directly query for
