# @golems/teller

TellerGolem — financial tracking, subscriptions, and tax preparation.

## What It Does

- Tracks subscriptions from email receipts
- Categorizes payments using LLM
- Generates monthly/yearly spending reports
- Identifies tax deductions (Schedule C)
- Alerts on spending anomalies

See [CLAUDE.md](./CLAUDE.md) for full architecture and Supabase tables.
