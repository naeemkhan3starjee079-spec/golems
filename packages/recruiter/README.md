# @golems/recruiter

RecruiterGolem — outreach pipeline, interview practice, and contact management.

## What It Does

- Finds hiring managers at target companies
- Drafts style-adapted outreach messages
- Tracks conversations and follow-ups
- Runs interview practice sessions with Elo ratings

## Pipeline

E1: Contact Finder -> E2: Outreach DB -> E3: Style Adapter -> E4: Auto-Outreach -> E5: Company Research -> E6: Obsidian Export
